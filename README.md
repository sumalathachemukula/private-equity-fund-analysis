# 📊 Private Equity Fund Analysis (SQL + Python)

## 📌 Overview
This project presents an end-to-end financial data analysis of private equity funds using SQL and Python.  
It focuses on evaluating fund performance, investor behavior, profitability, and ensuring data quality through validation checks.

---

## 🎯 Objectives
- Analyze capital calls and distributions across funds  
- Evaluate fund profitability using financial metrics  
- Generate investor-level insights  
- Perform data validation to ensure accuracy  

---

## 🛠️ Tools & Technologies
- SQL (MySQL / PostgreSQL)  
- Python (pandas, matplotlib)  
- Dataset (Excel / CSV)

## 📈 Key Analysis

### Fund Performance
- Total capital invested per fund  
- Total distributions  
- Net Asset Value (NAV)  
- Profit calculation  

### Investor Insights
- Total investment per investor  
- Average investment size  

### Trend Analysis
- Monthly capital call trends  

### Performance Metrics
- Return ratio (Distributions / Capital)  
- Fund ranking based on profitability  

### Data Validation
- Missing values detection  
- Negative values check  
- Duplicate records identification  
- NAV consistency validation  

---

## 📊 Sample Insights
- Some funds generate higher returns with lower capital investment  
- Investor contribution patterns vary across funds  
- Data validation revealed inconsistencies in NAV reporting
